# racemap - generator for the "Galaxy Grand Prix - World Tour v2" build script

The whole race world is generated by code and compiled into ONE build script (the format the Build tab's
"Make a build with an AI" section reads). Nothing here needs the game.

    python build.py                 # all zones -> out/galaxy_world_tour_v2.json  (~1.6M blocks, ~80k ops, ~12 MB)
    python build.py frost --ticks   # one zone, with a block count per step
    python build.py --render        # also out/top.png (top-down map)
    python verify.py                # kart roads: holes, non-road floor, head-room, step spacing
    python floodtest.py             # is the Abyss basin watertight? (flood fill from inside)
    python flightcheck.py           # anything solid on the plane's flight line / the sub lane?
    python info.py                  # out/map_info.md: zone lengths, lap estimate, trigger coordinates, water volume
    python sections.py              # out/sections.png: a cross-section of every zone's road
    python shots_zone.py start,meadows name x0 x1 z0 z1 [scale]   # top-down crop of some zones into out/
    python railtest.py              # ASCII picture of how the guard-rail chain turns corners

Expand the result the way the game does (raise the limit, the map is over the default 600,000):

    bs_cli.exe out/galaxy_world_tour_v2.json --names ..\ai_prefab_blocks.txt --max 2500000 --materials

v2 = the same world as v1 (layout.py, terrain and set pieces unchanged) rebuilt from the race server's own blocks:

* kart.py      materials (Kart_*, Red_Workwall, Rotatesign, Stack*, Finish_Line, NoCube neon), the orientation rules
               (which rot means what for rails / curbs / lines / arrows / signs / floodlights / flags), curvature + corner
               detection, finish band, start grid, zebra, arrows, `boost_pad` (neon chevrons set into the asphalt).
* kartroad.py  `stamp_kart_road`: Kart_Asphalt surface, optional neon edge strip, Kart_Concrete/Kart_Grass verge, ONE
               connected guard-rail chain per side (Armco / Barrier_Metal / Jersey / Tire_Wall / Chevron_Block, with the
               *_Corner pieces turned to follow staircase curves), optional wall behind it, deck + piers, then the flat
               decals on layer road+1: dashed lane lines, edge lines, rumble curbs on the inside of bends.
* kartprops.py corner warning signs (Rotatesign / _Left, facing the driver), tyre piles / hay bales on the outside of
               corners, skid marks, floodlight posts (pole + glow block + Kart_Floodlight leaning at the road), billboards and
               flags, cone gates, speed bumps. Everything checks there is ground under it (call it after the terrain).
* build.py     after all zones: `restore_roads` puts the stamped surface back wherever terrain / crystals overwrote it, then
               `clear_corridor` keeps 3 blocks of head-room over every kart road and only Kart decals on layer road+1.

The stadium road is flush with the ground (y = -1, markings at y = 0, exactly like the prompt's track rules); it steps up
to y = 0 just before the Meadows terrain (layout: build.set_heights).

Layout (layout.py): path A = start -> meadows -> canyon -> crystal -> abyss (sub) -> frost summit; path B = runway ->
volcano -> rainbow road -> back onto the start straight; the plane flight (sky) is a third path with an altitude per
sample.  Lap length was sized for kart 45 / plane 75 / sub 38 blocks per second (build.SPEED, info.py); change the
zone vertices in layout.py (A_ROWS, B rows, build_sky) to lengthen or shorten a zone.

Files: core.py (voxel world + emitter), path.py (centre lines, raster bands), terrain.py (heightfield skins),
kit.py (gates, signs, hoops, trees...), font.py (5x7 lettering), zone_*.py (one per zone). `styles.py` and
`path.stamp_road` are the v1 (generic blocks) road builder, kept for reference.
